# Problem Framing

Load only the method needed for the current decision. Follow its triggers, anti-triggers, and observable output. These methods grant no extra permissions.

- [socratic-clarification](references/socratic-clarification.md): Ask only the question whose answer changes the work.
- [first-principles](references/first-principles.md): Separate hard constraints from inherited assumptions; rebuild the options.
- [reverse-engineering](references/reverse-engineering.md): Infer plausible mechanisms from observed behavior; distinguish evidence from inference.
- [dual-layer-explanation](references/dual-layer-explanation.md): Use an intuitive explanation followed by its precise technical account when both help.
