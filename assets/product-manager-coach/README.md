# 产品经理教练：使用说明

本技能帮助零基础用户学会产品判断，并整理能交给AI或研发团队的工作材料。它支持一般软件产品，金融投研场景按需读取专门参考。版本：2026-11-19。

## 怎样开始

安装到 Codex 可发现的技能目录后，在新会话中显式调用：

```text
$product-manager-coach 我完全不懂产品。我在基金公司做机构客户投研软件，已有一个参考站和页面壳子。请先带我说明这个产品服务谁、解决什么问题。
```

也可以直接带着当前任务使用：

- `$product-manager-coach 客户让我们加AI问答，先帮我搞清要解决的问题。`
- `$product-manager-coach 我有十个想法，帮我决定下一版先验证什么。`
- `$product-manager-coach 这是当前需求说明，帮我找研发或AI接手时会理解不一致的地方。`
- `$product-manager-coach 本地曲线与参考站不一致，帮我列产品侧需要核对的口径和验收样本。`
- `$product-manager-coach 帮我把已经确认的小功能交给AI开发。`
- `$product-manager-coach 我准备让客户试用，帮我定义任务、记录观察并复盘。`

默认允许自动选择，但能否自动命中取决于当前宿主和请求；显式调用更方便确认使用了这个技能。仅有一个产物目录中的技能包，不等于已安装或已在当前会话加载。

## 它会怎样工作

先复用你给过的信息，再选择当前需要的模式。对关键缺口每轮问一两个问题，并解释选项和推荐理由；已有明确任务时直接产出材料。它不会要求新手先填完整套表格。

建议从一个小客户任务练习：客户研究 → 需求取舍 → 小功能规格 → 数据/AI评测 → 开发交接 → 试用复盘。教学示例“筛选、比较ETF并生成可核验摘要”不代表你的真实首版已经选定。

产物可以是产品一页纸、访谈记录、竞品借鉴表、需求排序、规格与验收用例、数据/AI评测卡、交接包或复盘。模板按需使用。

入口通过稳定章节锚点直达当前模式，无需为一个小任务通读全部模式。交给AI或研发时，模板会标明材料状态（草案/已确认）、已确认范围、确认前可执行范围和尚不可实施项。已确认任务直接交接，不重复请求批准；未决项不阻塞已确认且独立的任务。

## 带什么资料最有用

已有产品说明、客户的具体原话或反馈、参考页面、当前需求、已知数据口径和验收结果即可，不必一次准备齐。请标明真实资料、模拟内容和自己的猜测；不要提供凭证或不必要的客户个人信息。

用户要求保存时，优先使用指定位置；已有工作簿先读取再更新。已授权创建工作材料且没有指定位置时，默认在当前工作区 `outputs/` 保存 Markdown；没有写入授权或工作区时先在会话中交付。结束前可生成“会话接力”，下次把它交给技能继续。

## 文件与维护

- `SKILL.md`：技能入口、范围和证据要求。
- `agents/openai.yaml`：显示信息及自动发现策略。
- `references/modes.md`：按工作阶段使用的指导。
- `references/finance.md`：金融数据、策略与AI结果的验收问题。
- `references/templates.md`：可删减的材料模板。

维护源文件后同步这份使用说明，重新运行系统技能校验；改变行为后用真实任务或独立案例验证。结构校验通过不等于已证明行为正确、已安装或在所有会话中自动命中。

本包无脚本、无新增依赖，不改全局规则。安装由本次任务主代理负责；先确认目标目录无同名技能再复制，若已有则读取并比较后处理，不直接覆盖。

## 边界

它提供产品判断与材料，不会凭自身权限联系客户、发布、改生产系统或执行金融交易。你明确要求实现时，可将确认的材料交给当前工程流程。金融参考是验收提问清单；法规适用、数据授权、具体算法和生产结果需要对应证据与责任人确认。
