# 产品目标与验收

Super Agent 通过 Paperclip 统一管理个人跨项目任务。飞书负责输入和决策通知，GitHub 提供任务与交付事件，Codex 在限定工作区执行，项目适配层调用目标项目自己的验证和 Git 安全入口。

第一阶段服务本人，以 RWB 为首个外部项目；本项目自身也必须能交付受控任务。当前不建设多人权限平台、不重新实现调度引擎，不自动升级 RWB 常驻实例，不自动合并代办的 RWB PR。

## 两条真实完成标准

1. 本项目：Paperclip 执行一项操作指南文档任务，具有 Skills 加载证据、独立评审、适用本地检查、PR、同候选 CI、受保护合并及结果回传。
2. RWB：本人已绑定飞书验收会话发起任务，Paperclip 经隔离工作区新增受控任务交接说明，独立评审、RWB 必需检查通过后创建 PR，飞书回传；保持不合并、不部署。

两条都固定既有个人订阅、`gpt-6.1-sol` / `low`、独立开发与评审会话、每任务最多两轮修复。上海每日最多 10 个新任务，全局一个写者。输入不得扩大权限；未知远端结果先核对，不能重新调用模型或重复发布。

## 完成状态分层

源码交付记录提交、PR、评审和 CI；运行升级记录实际镜像、依赖、挂载和活动排空；业务验收记录任务全链及通知；资源收尾记录退休与回收。这四者独立，任一层受阻不抹去其他层证据，也不能用其他层 PASS 替代。

本轮只开放两条限定验收任务，结束后恢复暂停调度。长期无人值守启用另行审查；未覆盖行为保持未验收。
