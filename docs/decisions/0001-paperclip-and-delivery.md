# ADR 0001：Paperclip 主线与分层交付

日期：2026-11-04。状态：已选择，业务能力逐项验收。

采用 Paperclip 作为唯一目标调度引擎。本项目负责飞书、GitHub、项目权限与验证适配、Docker 生命周期和验收资产；不再并行运行旧自建核心。旧设计保存在 archive，以保留决策与恢复背景。

复用 leon-engineering 受管 Harness 和交付框架。本项目维护项目规则、文档治理、实际命令和证据，不复制框架或把项目事实升级为全局规则。

Super Agent 自身任务检查、独立评审及分支保护通过后可自动合并；代办 RWB 仍止于 PR。首次发布保留当前主线历史，其他实验分支留本地。私有仓库的保护不可用时阻断自动合并，不改成公开、不直接推送绕过。

文档区分现行规则、实现、计划、历史和日期快照。源码不证明部署，测试不证明真实业务，健康不证明空闲。默认未知失败关闭。

仅当 Paperclip 在明确候选下不能满足权限、恢复或可维护性要求，并有可复现证据时重新评估选型；新方案需新的决策与授权，不能因旧代码存在自动复活调度器。
