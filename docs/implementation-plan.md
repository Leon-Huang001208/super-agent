# 已批准的个人自动化系统 v1

## 结果

本地个人中台统一接收飞书任务和授权的 agent:ready Issue，持久化任务状态，使用 Codex 实施和独立评审，通过 ResearchWorkbench 的现有验证后交付 PR。

## 顺序

1. 事件去重、SQLite 状态机、队列、配额、决策与恢复。
2. Codex / Claude 执行器契约及 RWB 受管 Git、验证和远端写入。
3. 飞书长连接、GitHub 增量接入和单一通知出口。
4. 管理员认证、网页面板、安装预览和运维说明。
5. 离线故障测试、浏览器验证和受控 RWB 文档 PR 验收。

## 硬边界

单并发，每天 10 个新任务，最多两轮反馈修复；动作上限 PR；无自动模型切换或付费 API 回退。低于 5 GiB 不启动任务。外部输入不扩大权限，停止的任务不因机器人消息恢复。

依赖、飞书权限、Tailscale 和开机启动按各自授权要求配置。保留现有 RWB 常驻服务、业务资料、凭据和受保护资源。
